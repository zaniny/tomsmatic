# Changelog

На странице перечислены версии, для которых сохранились исходники или сборки. Ранние версии до импорта в Git восстановлены по архивам.

## 0.3.10

- Иконка мода показывает одинарный сундук в мягкой перспективе и длинный свиток с двумя отметками.
- У кнопки **Сверить схему** новый значок: контрастный квадратный сундук с бирюзовой галочкой.

## 0.3.9

- У кнопки **Сверить схему** новый значок: три светлые строки и крупная бирюзовая галочка в тонах маяка.

## 0.3.8

- Новая пиксельная иконка Tomsmatic в сведениях Fabric и Mod Menu.
- Кнопка **Сверить схему** теперь обозначена списком с галочками.
- Обновлены описание мода и инструкция по установке. Примечания к версии теперь берутся из этого журнала при сборке GitHub Release.

## 0.3.7

- Подсказка в отчёте показывает две строки **Всего** и **Не хватает** в стаках и штуках. Размер стака зависит от предмета.
- Цвета экранов и уведомлений собраны в одном классе.

## 0.3.6

- Добавлена колонка **Поставлено**. Дефицит учитывает блоки, которые совпадают с размещённой схемой, и запасы терминала.
- При открытии отчёта запускается свежая проверка размещения в Litematica.

## 0.3.5

- Tomsmatic запускает расчёт Litematica для выбранного размещения, если список ещё не готов.
- Уже открытый список имеет приоритет. Отчёт ждёт завершения подсчёта и затем запрашивает остатки.

## 0.3.4

- Остатки при открытии по хоткею загружаются в фоне и обновляются по мере поступления пакетов Tom’s Simple Storage.
- Добавлено сообщение о загрузке остатков.

## 0.3.3

- Убрано краткое появление окна беспроводного терминала при открытии отчёта по хоткею.

## 0.3.2

- Назначение и сброс хоткея списка в настройках Tomsmatic через Mod Menu.
- Esc отменяет назначение клавиши. Новая привязка сохраняется в настройках Minecraft.

## 0.3.1

- Подсказка в строке материалов показывает требуемое количество в стаках и штуках.
- Подсказки доступны также над числовыми колонками и кнопкой крафта.

## 0.3.0

- Отчёт открывается отдельным хоткеем или кнопкой в настройках Mod Menu.
- Колонка **Крафт** позволяет заполнить сетку терминала для рецепта, открытого в книге рецептов.

## 0.2.4

- Уведомления автовыдачи теперь подписаны именем Tomsmatic на русском и английском.

## 0.2.3

- Первая доступная сборка в истории. Кнопка в терминале сверяет список Litematica с остатками Tom’s Simple Storage.
- Опциональная автовыдача пополняет инвентарь для Easy Place через привязанный улучшенный беспроводной терминал. Установка Tomsmatic на сервере включает бесшовную выдачу.
